# Modelos locais gerados

Esta pasta existe como ponto de montagem para os modelos criados/exportados pelo Nymi Gacha durante o uso local.

## Regra do repositório

- Arquivos gerados de personagens/modelos **não pertencem ao Git**.
- Somente este `README.md` deve ser rastreado.
- O aplicativo pode recriar/preencher a pasta localmente.
- Dados reais do usuário ficam fora da árvore versionada e devem ser protegidos por backup próprio.

A separação evita que centenas de megabytes de PNGs produzidos no uso diário sejam misturados ao código-fonte.
