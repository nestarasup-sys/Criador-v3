# Ferramentas

Área independente para ferramentas auxiliares do Nymi Gacha.

Cada ferramenta deve permanecer em sua própria subpasta, sem compartilhar
estado ou implementação com Criador, Studio, Roteiros ou Base de dados até que
essa integração seja planejada explicitamente.

## Ferramentas

- `public/Ferramentas/green-bg-pro/index.html` — Green BG PRO, ferramenta integrada em modo legado.
- `public/Ferramentas/alinhador-profissa/index.html` — Alinhador Profissa, ferramenta integrada em modo legado.
